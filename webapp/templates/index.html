EDUCATIONAL VIEW
THE KEY DISTINCTION

Security vs. puzzle mechanics

AES-256-GCM provides confidentiality and tamper detection. Encodings and keyboard mappings make the result interesting to solve, but are not extra encryption.

⌘

Encryption stages

STAGE 01 / 06
⌕

Input detection

CipherKeys checks the characters in your message. Hangul-only text uses the Korean 2-beolsik route; English, mixed scripts, punctuation and other text use UTF-8 directly.

EXAMPLE안녕 → Korean route
Hello! → UTF-8 route
This is routing logic, not encryption. It makes sure the original text can be restored correctly.

SECURITY NOTES

Protect your secret key

  • Share puzzle and key through separate channels.
  • Never commit real key files to GitHub.
  • Anyone with the key and puzzle can decrypt the message.
  • Keep the terminal running only while using the app.
